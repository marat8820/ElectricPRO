# Электрик PRO

Android-приложение — помощник для профессиональных электриков.

## Возможности

- Электрические калькуляторы
- Расчёт мощности, тока и напряжения
- Расчёт кабеля и падения напряжения
- Справочник электрика и электрические схемы
- Сметы и учёт материалов
- Учёт клиентов и объектов
- Платная подписка на расширенные функции

## Платформа

Android

## Язык приложения

Русский
