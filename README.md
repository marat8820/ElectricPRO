# ElectricPRO v1.1

Native Android Java app. The interface has been rebuilt to follow the dark navy/yellow mockup, with a 2x2 home menu, wire calculator, lighting calculator, safety section and electrical reference.

## Build
GitHub Actions builds `app-debug.apk` after a push to `main`/`master` or manual workflow dispatch. Download the artifact named `ElectricPRO-v1.1-debug`.

## Important
Calculations are approximate educational aids, not a substitute for electrical design, local standards, or qualified professional assessment.
